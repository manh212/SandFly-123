SandFly 1.0 is the first stable release of this fork. It builds on SandFly by aaron-gh, which builds on Google's TalkBack — thank you to both for the open-source screen reader this project stands on.

## New in this fork

* Direct key input: an on-screen keyboard typing method that commits the key under your finger when you lift, for fast slide-and-lift typing. Settings > On-screen keyboard > Typing method.
* Faster screen changes: windows settle in about 20 ms (down from ~200 ms) before the window name is read, so new screens start being read almost immediately.
* Translate the last spoken phrase, fully offline with ML Kit: the last thing SandFly said is translated with one gesture. Settings > Feedback > Offline translation.
* Timer and stopwatch: announce the time on a schedule and count time with vibration or sound reminders. Hold volume up on the lock screen to start or stop the stopwatch. Settings > Timer.
* Volume key settings: six gesture slots for volume up and volume down (press, hold, hold on the lock screen). Settings > Volume keys.
* Export diagnostics: export or copy everything needed for support into Downloads — device and app info, SandFly state, an audio snapshot, the last crash and the recent log. Settings > Developer settings > Export diagnostics. It replaces the built-in problem report, which is removed.
* Notifications screen: per-app notification states and rules live on their own screen instead of filling the main settings screen. Settings > Notifications.
* Web selection mode switch: when "Change reading control in selection mode" is off, no reading control is changed automatically in web content. Upstream behavior is unchanged when it is on.
* The two legacy voice-input gesture actions now say Gboard in their names, so they can't be confused with the new Dictate action.
* The in-app tutorial was rewritten for this fork: corrected copy/paste and text-selection lessons, two pages promoting other Google apps removed, and new pages for the features above.
* Dictation keeps the words already recognized when a recognition session fails and retries with a growing back-off before giving up, for long utterances on Google on-device and Android recognition.

## New from the upstream SandFly 0.1.7 sync

* Dictation rewritten: Google on-device, Android, Rambler (Gemini live transcription with your own API key) and Whisper recognition, with AI cleanup of the text for the on-device engines.
* Container navigation: jump between toolbars, tab bars, search bars and panes, and browse mode for a physical keyboard.
* Capital letters can have a higher pitch or a sound on keyboard keys.
* System UI notifications are no longer read twice when only their details change.
* AI services: the AI service list and selection were reworked; with no service set up, descriptions and questions say so.

## Changes

* The built-in problem report ("Send feedback") is removed; report issues by exporting diagnostics instead.
* Gestures that don't map to an Android framework gesture ID (edge swipes, pinch/spread, rotate, scrub, and friends) were removed; only gestures that map to a framework gesture ID are available.
* This fork has the same application ID as the original SandFly but a different signing key: uninstall the original aaron-gh build before installing this one.
* README and the feature comparison were rewritten for this fork: SandFly here is phone-only and ships in English and Vietnamese only.

## Known limitations

* Dictation has no default gesture; assign one in Settings > Gestures to the "Dictate" action.
* If dictation says "No speech was recognized" after another screen reader used the microphone, force-stop the "Speech Recognition & Synthesis" app in Android settings and try again instead of rebooting the phone.
* In long sessions of very fast interaction the speech queue can grow a tail (up to about 0.8 s); restarting SandFly clears it.
* Phone only, English and Vietnamese only.

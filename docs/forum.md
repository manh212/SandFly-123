# Meridian community forum

The forum is part of Meridian and supports text-only discussion. Its five categories are Thảo luận chung, Hỏi đáp, Chia sẻ, Đề xuất tính năng, and Hướng dẫn sử dụng.

Members can create topics, comment, reply, like, and use polls. Topics are ordered by recent activity, with pinned topics shown first. Authors can edit, delete, and lock their topics. The forum includes notifications for replies and mentions, and a separate Nhắn tin screen for private conversations with the owner.

The public interface presents short, accessible labels without displaying operational or moderation rules. The one-touch reporting action does not ask for a reason or confirmation. There are no attachments, external sharing, or search.

## Installation

The forum is accessed from the Meridian settings screen. The owner uses Meridian Quản trị for administrative functions. The current Firebase database Rules must be separately reviewed and deployed by the owner. Merely shipping an APK does not modify the production database. GitHub Actions is responsible for all project builds and automated tests after source publication approval.
